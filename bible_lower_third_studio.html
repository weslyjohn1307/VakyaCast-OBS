OBS Studio & Standalone Broadcast Setup

⚡ Automatic Setup (Windows 1-Click Installer)

Recommended

Download and run the automatic setup script in the same folder as this HTML file. It automatically creates C:\OBS-VakyaCast\, generates obs_dock.html & obs_overlay.html, builds an importable OBS Scene JSON, creates a Standalone Desktop App shortcut, and copies the Dock URL to your clipboard!

Manual Setup Inside OBS Studio (2 Minutes)

  1. Add the Control Dock in OBS: Go to top menu Docks → Custom Browser Docks, set Dock Name to Bible Lower Third, and paste this URL:
    file:///C:/OBS-VakyaCast/bible_lower_third_studio.html?mode=dock
  2. Add the Transparent Overlay in OBS: In your Scene, click + → Browser, uncheck "Local file", set Width 1920 & Height 1080, and paste this URL:
    file:///C:/OBS-VakyaCast/bible_lower_third_studio.html?mode=overlay

Standalone Mode (Outside OBS / Dual Monitor / Chroma Key)

Click "↗ Pop-out Overlay" in the top bar. It opens a synchronized broadcast overlay window you can place on a second monitor/projector or capture via Window Capture.
